# Supply Outreach Funnel Tracker (demo prototype)

A small Streamlit app showing how I would run the tracking layer for a
high-volume outbound talent-acquisition pipeline: stage-by-stage funnel
conversion, tripwire exception alerts, cohort-aware reply measurement,
per-source decomposition, and a structured experiment log.

**All data is synthetic sample data generated in `app.py` for demonstration.
No real candidate, company or campaign data is used. Thresholds are
adjustable illustrations, not industry rules.**

Built as an interview demo for the MAVI Growth & Strategy Operations
Associate role (Nov 2026).

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
